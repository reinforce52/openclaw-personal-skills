# 五大交付物制备指南

覆盖初赛三大件 + 决赛两大件 + 全国赛技术文档。每项给出结构、写作/制作要点、常见失分点。

## ① 项目申报书

模板见 `assets/application_doc_template.md`（官方模板到货后以官方为准，本模板保证字段不缺）。

**必须包含的四大块**（海之子杯初赛明文要求）：

1. **项目背景**：政策（双碳、AI+行动、绿色建筑）→ 行业痛点（从业人员具体痛点，1-2 个真实场景）→ 为什么现在做（大模型/Agent 技术成熟）。忌空喊口号，用数据支撑（如建筑运行碳排放占比 30% 等，须标注来源）。
2. **技术方案**：系统架构（分层）+ 核心链路（输入→规划→工具调用→输出）+ 关键技术（Agent 编排、RAG、计算引擎、模型选型）+ 数据来源。必须与 1 页架构图一致，能闭环可跑。
3. **创新点**：2-3 个，每个一句话说清"别人怎么做的 → 我们怎么不同 → 带来什么价值"。创新点必须**可被评审验证**（演示时能当场展示）。
4. **应用场景**：使用者画像（从业人员）、典型使用流程（3-5 步）、落地价值（效率/成本/减碳量级）、推广可行性。

**写作要点**：
- 全文"去 AI 味"：少用"赋能、抓手、闭环、多维度"等空词；多用具体数字、具体场景、具体操作
- 技术方案写"我们能跑通的方案"，不写"我们打算探索的方案"
- 引用规范（GB/T 51366-2019 等）必须写对全称

## ② Demo / 演示视频（≤5 分钟）

**脚本结构**（5 分钟黄金配比）：

| 时间段 | 内容 | 要点 |
|---|---|---|
| 0:00-0:30 | 痛点开场 | 从业人员视角一句话痛点 + 现状对比 |
| 0:30-1:30 | 方案展示 | 核心界面/交互演示，讲清"输入→输出"闭环 |
| 1:30-3:30 | 关键能力演示 | 现场跑通 2-3 个真实案例（数据必须真实） |
| 3:30-4:30 | 创新点收束 | 逐条对应申报书创新点，现场验证 |
| 4:30-5:00 | 落地价值 | 场景/效益/展望 + 结束语 |

**录制规范**：
- 录屏 1080p，窗口干净（关通知弹窗），字体调大
- 中文配音或字幕二选一（避免字幕+配音同时密集出现）
- 演示前预演 3 遍，掐表；宁可 4 分 30 秒也不超 5 分钟
- 网络不可控的环节（云端 API）改为本地演示或提前录制真实结果画面
- 若 AI 生成视频/配音，保留可复现的参数说明

## ③ 1 页技术架构图

模板与要素见 `assets/architecture_diagram_template.md`。

**硬性要求**：
- **一页**（A4 横向或 16:9），字小但不糊，评审放大能看清
- 必须画出**数据流**（不只是静态框图）：标注数据从哪来、经过哪个模块、输出到哪
- 分层清晰：用户层 / 应用层 / 智能体编排层 / 工具与计算层 / 数据层 / 模型层
- 与申报书技术方案、演示视频中的系统一一对应，三处不一致是硬伤

**工具建议**：draw.io / Excalidraw（免费可导出）、PPT 手绘、或 HTML/SVG（可交互）。Mermaid 可快速出初稿再美化。

## ④ 现场演示（决赛/总决赛）

**流程**（10 分钟答辩标配）：
1. 30 秒电梯陈述（是什么+为谁+解决什么）
2. 3 分钟系统演示（走真实场景闭环，预置 2 套数据：主演示 + 备用）
3. 2 分钟创新点与工程价值
4. 答辩 Q&A

**应急预案（必须演练）**：
- 网络断开 / API 限流 → 本地模型（Ollama）兜底，模型权重提前下载
- 现场设备无显卡 → 准备 CPU 可跑的最小演示路径（规则引擎 fallback）
- 演示数据丢失 → 备用数据文件放 U 盘 + 云端各一份
- 提前到现场测试投影分辨率与字体大小

## ⑤ 完整源码仓库

**必备结构**：

```
project/
├── README.md          # 项目简介、架构说明、快速开始、目录结构
├── requirements.txt   # 依赖锁定（pip freeze 导出）
├── .env.example       # 环境变量模板（不含真实密钥）
├── src/               # 核心代码（智能体编排、工具、计算引擎）
├── data/              # 演示用脱敏数据 + 说明
├── docs/              # 技术文档（架构/算法/接口说明——全国赛要求）
├── tests/             # 冒烟测试（证明能跑）
└── LICENSE            # 选开源许可证
```

**README 必含**：一键运行命令（`pip install -r requirements.txt && python app.py`）、环境要求（Python 版本、显卡、Ollama 等）、依赖的第三方服务。

**避坑**：不要把 API key/真实数据提交仓库；用 `.gitignore` 排除 `__pycache__`、`.env`、模型权重；提交前 `git clean -nd` 检查。
