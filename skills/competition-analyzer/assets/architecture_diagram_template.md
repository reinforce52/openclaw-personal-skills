# 1 页技术架构图模板

## 一、必备要素（评审视角逐项自查）

1. **分层结构**（自上而下）：用户层 → 应用层 → 智能体编排层 → 工具与计算层 → 数据层 → 模型层
2. **数据流标注**：每条关键数据通路用箭头 + 文字说明（数据从哪来 → 经哪模块 → 输出到哪）
3. **核心模块命名**：与申报书技术方案、演示视频里的系统名称完全一致
4. **一页原则**：A4 横向或 16:9，信息密度适中，评审放大 200% 仍清晰
5. **边界标注**：本地部署部分 vs 云端服务部分分开标注（答辩讲得清）

## 二、Mermaid 初稿示例（可转 SVG/HTML 美化）

```mermaid
flowchart TB
    subgraph User["用户层"]
        U1["从业人员<br/>（绿建咨询/造价工程师）"]
    end

    subgraph App["应用层"]
        A1["对话界面<br/>Gradio/Streamlit"]
        A2["报告生成<br/>（分项碳排报告+建议）"]
    end

    subgraph Agent["智能体编排层"]
        AG1["意图识别与规划"]
        AG2["工具调用调度<br/>（ReAct/LangGraph）"]
        AG3["上下文记忆"]
    end

    subgraph Tool["工具与计算层"]
        T1["碳排放计算引擎<br/>GB/T 51366-2019"]
        T2["标准/规范检索<br/>（RAG）"]
        T3["可视化图表"]
    end

    subgraph Data["数据层"]
        D1["碳排因子库"]
        D2["项目参数数据<br/>（脱敏样例）"]
        D3["标准文档库"]
    end

    subgraph Model["模型层"]
        M1["本地模型<br/>Ollama+Qwen2.5"]
    end

    U1 --> A1
    A1 --> AG1
    AG1 --> AG2
    AG2 --> T1
    AG2 --> T2
    AG2 --> T3
    T1 --> D1
    T1 --> D2
    T2 --> D3
    AG3 --> AG1
    A1 --> A2
    A2 --> U1
    M1 --> AG1
```

## 三、绘制规范

- **工具**：draw.io / Excalidraw 导出 PNG/SVG（最终图用矢量，放大不糊）；Mermaid 出初稿
- **配色**：分层用同一色系深浅区分，数据流箭头用高对比色；避免大段文字堆在框里（每框 ≤ 8 字 + 括号说明）
- **数据流文字**：在箭头上标"参数输入""计算结果""因子查询"等动作词
- **检查**：打印 A4 检查字号；找队友盲读 30 秒能否讲清数据流向
