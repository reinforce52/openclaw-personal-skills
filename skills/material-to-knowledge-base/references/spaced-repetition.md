# 间隔重复规则（Spaced Repetition）

驱动 `_复习清单.md` 与每篇笔记的 `review_status` / `next_review`。

## 状态流转

| 当前状态 | 触发动作 | 下次复习间隔 |
|---|---|---|
| `new`（新学） | 首次学习完成 | +1 天 |
| `learning`（学习中） | 自我检测基本通过 | +3 天 |
| `review`（复习中） | 自我检测通过 | +7 天 |
| `mastered`（已掌握） | 连续通过 | +15 天 |
| 任意状态 | 自我检测答错 | 回退一级，间隔减半（如 review→learning，+3 天） |

## 使用规则

- `_复习清单.md` 每次新增笔记或复习状态更新后重新生成/更新。
- 每天需要复习的知识点由 `next_review <= 当天` 决定。
- `next_review` 初始值：`created + 1 天`。
- 更新时机：用户反馈"学会了/忘记了"或复习动作完成后。
