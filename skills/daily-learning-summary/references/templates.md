# 模板参考（Daily Learning Summary）

本文件供 SKILL.md 工作流引用，生成内容时按此结构输出。

## 1. 每日日志模板（01-每日日志/Daily/YYYY-MM-DD.md）

```markdown
---
date: {{date}}
tags: ["每日学习记录"]
---
## 📘今日学习项目
- 项目名称：
- 信息来源：项目daily_summary.md / Git代码变更 / OpenClaw补充
- 做了哪些：读代码/调试复现/原理学习/刷题
- 掌握内容：
## 🧠今日学到知识
- 知识点1
- 知识点2
## ⚠️遇到问题 & 解决方案
> 报错、环境坑、概念误区完整记录
## 📝简历可提取亮点
> 1-3条简短片段，可以直接复制简历
## 📅明日计划
- 任务1
- 任务2
## 🔗双向链接
[[对应项目文档]] [[对应学科知识点]]
## ❓今日复习题（间隔重复）
> 基于今日知识点出 3 道，供明日自测
- Q1：...　A：...
- Q2：...　A：...
- Q3：...　A：...
```

## 2. 项目库文档模板（03-项目库/{项目名}/README.md）

```markdown
---
project_name: ""
tags: ["土木视觉","机器视觉","OpenCV","PyTorch"]
status: 进行中 / 已完成
---
# {{项目名称}}
## 项目简介
## 环境依赖
## 核心技术点学到什么
## 关键代码片段
## 踩坑记录（报错、排错步骤）
## 项目产出 & 简历可用描述
## 后续待做
🔗关联：[[每日日志]] [[相关知识点]]
```

## 3. 学科学习库（02-学习库/{学科名称}/）

每学科目录下含三类笔记（按需生成，各自成文件或分区）：
- **费曼总结**：用自己的话讲清概念（费曼式中文，清晰直白）
- **易混淆概念**：成对对比（如：目标检测 vs 实例分割；PID vs 前馈控制）
- **错题笔记**：题目/错误答案/正确答案/错误原因/同类题注意点

## 4. 简历素材库（04-简历成长库/简历素材库.md）

- 持续追加"可直接复制粘贴"的片段：项目经历、技术栈、成果描述
- **只产出素材片段，不自动生成完整简历**

## 5. 占位日志（容错，P1）

当日无有效素材时，按每日日志模板生成，并在顶部标注：

```markdown
> ⚠️ 当日无有效学习素材（daily_summary.md 缺失或无 git 变更），以下为占位记录，待补充。
```
