# 初始量表：BFI-10 大五人格 + VARK 学习风格

> 用途：personal-twin 初始化。约 10 分钟。结果是人格/学习风格"锚点"，非心理诊断。
> 作答：第一部分每题 1-5 分；第二部分每题选 V/A/R/K（可多选）。
> 答完交给 `scripts/score_questionnaire.py` 计分。

---

## 第一部分：BFI-10（大五人格，10 题）

请按"我有多符合这句话"打分：**1=非常不同意，2=比较不同意，3=中立，4=比较同意，5=非常同意**。
凭第一直觉，不要过度思考。（R 为反向题，计分时脚本自动处理，你正常打分即可）

| 题号 | 陈述 | 你的分(1-5) |
|---|---|---|
| Q1 | 我比较含蓄、安静（R） |  |
| Q2 | 我通常愿意信任他人 |  |
| Q3 | 我有时会偷懒、拖延（R） |  |
| Q4 | 我情绪放松，能较好地应对压力（R） |  |
| Q5 | 我对艺术、审美没太大兴趣（R） |  |
| Q6 | 我外向、好交际 |  |
| Q7 | 我倾向于挑别人的毛病（R） |  |
| Q8 | 我做事彻底、认真可靠 |  |
| Q9 | 我容易紧张 |  |
| Q10 | 我想象力活跃、好奇心强 |  |

维度归属与计分（脚本自动，仅供理解）：
- 外向性 E = Q6 + (6−Q1)
- 宜人性 A = Q2 + (6−Q7)
- 尽责性 C = Q8 + (6−Q3)
- 神经质 N = Q9 + (6−Q4)
- 开放性 O = Q10 + (6−Q5)
（每维 2-10 分，≥7 偏该维度高，≤4 偏低，5-6 居中）

## 第二部分：VARK 学习风格（16 题，每题选最符合你的选项，可多选）

V=视觉(图/表/空间) A=听觉(听/说/讨论) R=读写(文字/清单/文档) K=动觉(动手/实操/体验)。
每题从 4 个选项里选最像你的（可多选，拿不准就单选）。

**1. 学一个新软件/设备，你最希望：**
- a) 看带图的操作示意　b) 找人给我口头讲一遍　c) 看文字说明/手册　d) 直接上手试

**2. 去一个从没去过的地方，你最想要：**
- a) 一张地图　b) 别人口头指路　c) 文字路线（第几个路口转）　d) 凭方向感实地走一遍

**3. 老师讲一个难懂的概念，你最容易接受：**
- a) 一张示意图/流程图　b) 课堂讨论或讲解音频　c) 条理清晰的文字笔记　d) 一个真实例子或实验

**4. 你最容易记住什么：**
- a) 见过的画面、人脸、图表　b) 听过的话、旋律　c) 读过写过的文字　d) 做过的事、身体经验

**5. 解决一个问题，你倾向：**
- a) 在纸上/脑里画出关系　b) 跟人讨论或自言自语梳理　c) 列步骤、写下来　d) 边做边试、动手验证

**6. 复习备考，你最喜欢：**
- a) 看思维导图、图表总结　b) 听录音/互相提问背诵　c) 反复读写整理笔记　d) 做题、做实验、实操演练

**7. 一份好的教程，你最看重：**
- a) 图示多、排版直观　b) 有讲解音视频　c) 文字准确、逻辑清楚　d) 有大量可动手的练习

**8. 学习时你通常：**
- a) 需要看到板书/画面　b) 喜欢边听边说　c) 喜欢做大量文字笔记　d) 坐不住、想动手操作

**9. 别人向你解释事情，你希望他：**
- a) 画图说明　b) 当面/语音讲清楚　c) 发文字给你看　d) 带你实际走一遍/演示

**10. 你觉得自己最擅长：**
- a) 空间想象、配色构图　b) 表达、倾听、辩论　c) 文字、逻辑、归纳　d) 操作、运动、动手组装

**11. 遇到看不懂的内容，你会先：**
- a) 找配图/视频画面　b) 找人讲/听讲解　c) 找文字资料反复读　d) 直接动手试错

**12. 参加培训/讲座，你收获最大的是：**
- a) PPT 图表和演示画面　b) 讲者的口述和互动　c) 发的讲义和文字材料　d) 现场练习和案例操作

**13. 要向别人说明你的想法，你会：**
- a) 画个图　b) 直接说　c) 写一段文字　d) 拉着他一起做一遍

**14. 放松时你更可能：**
- a) 看展/看影像　b) 听播客/音乐/聊天　c) 看书/写东西　d) 运动/手工/外出活动

**15. 组装家具，你会：**
- a) 看组装示意图　b) 让人念步骤给你听　c) 先读文字说明　d) 直接拿零件试着拼

**16. 你认为最有效的学习是：**
- a) 看图理解　b) 听讲与讨论　c) 阅读与写作　d) 实践出真知

> 计分：统计你选 a/b/c/d 的数量（a=V, b=A, c=R, d=K），多选在对应维度各计 1。
> 最高的即主导风格；两个接近为双主导。
